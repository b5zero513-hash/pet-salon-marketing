# Salon Letter

ペットサロン向けの販促文作成デモです。店舗とキャンペーンの情報から、Instagram投稿文・LINE配信文・チラシ原稿を媒体別の構成で作成します。

## 起動方法

Node.js 18以降を使います。

```sh
npm install
npm run dev
```

本番向け静的ファイルは `npm run build` で `dist/` に生成されます。`dist/` を静的ホスティングで配信できます。

## 操作方法

1. 初期状態のサンプル情報を確認するか、店舗・企画情報を書き換えます。
2. Instagram、LINE、チラシから作成したい媒体を選びます。
3. 「販促セットを作る」を押します。
4. 出力カードの文章を編集し、必要な文章をコピーします。

料金・期間・条件が未入力の場合は出力に補いません。予約先が空欄の場合は、架空の連絡先の代わりに入力を促します。

## 第1版の範囲

- React + TypeScript + Viteによる静的なシングルページアプリです。
- 文章はブラウザー内のテンプレートで作成します。AI API、サーバー、ログイン、保存機能はありません。
- 入力内容は画面内だけで処理し、送信・保存しません。
- 初期入力の「こもれびトリミング」と予約方法は架空のデモ用情報です。実在の店舗・予約先として使用しないでください。
- SNS投稿、LINE配信、予約受付は実行しません。作成した文章は店舗で内容を確認・編集してからご利用ください。

詳細な仕様と今後の拡張方針は [PLAN.md](./PLAN.md) を参照してください。
